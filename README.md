# Portfólio Jefferson de Souza

## 🎼 Conceito: Sinfonia Ciberpunk

Fusão única entre a **erudição clássica** (medicina, psicanálise, música clássica, arquitetura do século XX) e o **futurismo ciberpunk** (neon, tecnologia, IA).

> "Entre a Medicina, a Psicanálise e o Código."

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura semântica
- **CSS3** — Variáveis customizadas, Grid, Flexbox, animações
- **JavaScript Vanilla** — DOM manipulation, Intersection Observer, scroll suave
- **Google Fonts** — Playfair Display (clássica) + Inter (moderna)
- **Git & GitHub** — Versionamento e deploy

---

## 📂 Estrutura do Projeto

```
portfolio/
├── index.html          # Página principal (Sinfonia Ciberpunk)
├── css/
│   └── style.css      # Estilos: dark theme, neon, clássico
├── js/
│   └── script.js     # Interações: preloader, menu, scroll
├── assets/            # Imagens (profile, fotos, ícones)
└── README.md          # Este arquivo
```

## ✨ Funcionalidades

### 🎹 Design & UX
- **Tema Dark**: Fundo `#0a0a0a` com dourado `#d4af37` e neon ciano `#00ffff`
- **Tipografia**: Clássica (Playfair Display) + Moderna (Inter)
- **Elementos Arquitetônicos**: Molduras douradas, linhas de partitura musical
- **Responsividade**: Mobile-first com media queries

### 🎹 Seções
1. **Hero** — Apresentação com foto em moldura arquitetônica
2. **Movimentos** — Carrossel infinito (Medicina, Psicanálise, IA, Calistenia)
3. **Sobre Mim** — Trajetória acadêmica e interesses
4. **Composições** — Projetos (Simulador de Triagem, Agente Psicanalítico)
5. **Instrumentos** — Habilidades (Medicina, Psicanálise, Dev, Música)
6. **Filosofia** — Diferenciais competitivos
7. **Encore** — Contato (Email, LinkedIn, GitHub)

### ⚡ Interatividade JS
- Preloader com nota musical pulsante
- Menu hambúrguer para mobile
- Scroll suave em links internos
- Revelação de seções com Intersection Observer
- Header com opacidade dinâmica ao rolar
- Carrossel infinito de "Movimentos"

2. Em **Branch**, selecione `main` e `/ (root)`
3. Clique em **Save**
